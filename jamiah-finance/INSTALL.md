# ইনস্টলেশন — সংক্ষিপ্ত

পূর্ণ নির্দেশিকা (রোল, রুটিন, ব্যাকআপ, সমস্যা সমাধান) আলাদা ডকে আছে।
এখানে শুধু বসানোর ধাপগুলো।

## ১. ফাইল রাখুন

জিপটি আপনার অ্যাপের মূল ফোল্ডারে খুলুন। `routes/`, `views/`, `public/`,
`lib/` — এগুলো আপনার বিদ্যমান ফোল্ডারেই যোগ হবে, কিছু মুছবে না।

`db/` ফোল্ডারটি নতুন — SQL ও ইনস্টলার সেখানে।

## ২. প্যাকেজ

```bash
npm install mysql2 qrcode
```

## ৩. ডেটাবেস

**আলাদা ডেটাবেসে রাখুন।** এই মডিউলের ২৫টি টেবিলের মধ্যে `accounts`,
`receipts`, `donors`, `campaigns` এর মতো নাম আছে যা আপনার বিদ্যমান
অ্যাপেও থাকতে পারে। আলাদা ডেটাবেসে রাখলে কিছুই ভাঙে না — এই মডিউলের
কোনো টেবিলের সাথে আপনার `students` বা `users` টেবিলের ফরেন কি নেই,
শুধু `finance_role` কলামটি আপনার `users` টেবিলে যোগ হবে।

ইনস্টলার চালানোর আগে নিজেই ২৫টি নাম যাচাই করে; সংঘর্ষ পেলে থেমে যায়।


**cPanel থাকলে** আগে cPanel → MySQL Databases থেকে ডেটাবেস ও ইউজার বানান।
Collation অবশ্যই `utf8mb4_unicode_ci`। তারপর:

```bash
cd db
node setup-db.js --user <ইউজার> --pass '<পাসওয়ার্ড>' --db <ডেটাবেস>
```

**নিজের সার্ভার হলে** এক কমান্ডেই:

```bash
cd db
node setup-db.js --user root --pass '****' --db jamiah --create
```

আর্থিক বছর ক্যালেন্ডার বছর না হলে:

```bash
node setup-db.js --user root --pass '****' --db jamiah --create \
  --fy-name '2026-2027' --fy-start '2026-07-01' --fy-end '2027-06-30'
```

ইনস্টলার নিজেই সব যাচাই করে জানাবে। ১১টি ✅ এলে ডেটাবেস প্রস্তুত।

## ৪. রোলের কলাম

```sql
ALTER TABLE users
  ADD COLUMN finance_role
    ENUM('none','accountant','chief_accountant','principal','committee')
    NOT NULL DEFAULT 'none';

UPDATE users SET finance_role = 'principal' WHERE id = <মুহতামিমের আইডি>;
```

## ৫. app.js

`mount-example.js` খুলে অংশটুকু নকল করে নিজের `app.js` এ বসান।
আপনার `requireAuth` ও লেআউট ফাংশনের নাম বসিয়ে নিন।

## ৬. সাইডবার

```html
<a href="/admin/receipts">রশিদ</a>
<a href="/admin/donors">দাতা ও স্পনসর</a>
<a href="/admin/orphans">এতিম শিক্ষার্থী</a>
```

## ৭. চালু করে দেখুন

অ্যাপ রিস্টার্ট করে এগুলো খুলুন:

- `/admin/ledger` — ৮টি ফান্ডের কার্ড
- `/admin/receipts/new?type=ZAK` — পরিমাণে 12500 লিখলে নিচে
  «বারো হাজার পাঁচশত টাকা মাত্র» দেখাবে
- `/admin/donors/campaigns` — তিনটি নমুনা প্রচারাভিযান
- `/admin/orphans/pool` — «সব শিশুর স্পনসরশিপ পূর্ণ»

একটি পরীক্ষামূলক রশিদ কেটে প্রিন্ট পেজে QR আসে কি না দেখুন,
মোবাইলে স্ক্যান করে `/verify` খোলে কি না দেখুন, তারপর সেটি বাতিল করে দিন।

## ৮. যা বাকি রইল

**CSRF টোকেন** — আপনার প্যানেলে এখন নেই। এখন POST দিয়ে টাকার এন্ট্রি হবে,
তাই এটা বসানো দরকার। পূর্ণ নির্দেশিকার «ধাপ ৮» দেখুন।

**এতিমদের কাগজ** — `public/` এর ভেতরে রাখবেন না। আলাদা ফোল্ডারে রেখে
রোল যাচাই করে পরিবেশন করুন (`mount-example.js` এর শেষ অংশ)।

## সমস্যা হলে

ইনস্টলার প্রতিটি ত্রুটির সাথে সমাধানও বলে দেয়। সবচেয়ে সাধারণ দুটি:

| ত্রুটি | সমাধান |
|---|---|
| বাংলা লেখা `????` | ডেটাবেসের collation `utf8mb4_unicode_ci` করুন |
| টাকার অংক স্ট্রিং | পুলে `decimalNumbers: true` আছে কি না দেখুন |
| তারিখ একদিন পিছিয়ে, বা `Thu Nov ০৫` | পুলে `dateStrings: true` যোগ করুন |
